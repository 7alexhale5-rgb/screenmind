# ScreenMind workspace

ScreenMind turns recordings into local frames, text and timelines. This system map keeps
server.py and the existing install and launch entrypoints where their tools expect them.
Start with CLAUDE.md, pick screenmind/, docs/ or .planning/, then read that room's CONTEXT.md.
Stable implementation decisions live in _reference/decisions.md; changing work status lives
in .planning/ and the changed record. File creation never means human review passed.
First check: run the shared ICM checker, then the compile and test commands in CLAUDE.md.
